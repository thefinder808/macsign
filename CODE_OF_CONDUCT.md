# Code of Conduct

MacSign adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, as its code of conduct. The full text is available at that link.

## In short

Everyone interacting in this project's issues, pull requests, and discussions is
expected to be respectful and constructive. Harassment, personal attacks, and other
unwelcome behavior are not tolerated. The goal is a friendly, professional space where
people can collaborate on the software.

## Reporting

If you experience or witness unacceptable behavior, please report it privately to the
maintainer via [GitHub](https://github.com/thefinder808). Reports will be reviewed and
handled confidentially. The maintainer is responsible for enforcement and may remove
comments, commits, issues, or contributions that violate this Code of Conduct.

For the full set of guidelines, enforcement guidelines, and scope, see the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
